# Dental clinic site with online booking

A clinic that took every appointment by phone. 3-step online booking, 100/100 PageSpeed on mobile.

**Live:** https://dmitrii-mazurkevich.github.io/dental-clinic-website/

![Dental clinic site with online booking](preview.png)

## Built with

HTML, CSS, JavaScript, Schema.org Dentist. Static site without a build step: open `index.html` or publish the folder to any hosting.
English and Russian versions with a language switcher, layout for phones and desktops.
